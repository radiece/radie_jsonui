## Reporting a Vulnerability

We take the security of `radie_jsonui` seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

Please send an email to <radiece@gmail.com>.

You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.

### Information to Include

Please include as much of the following information as possible:

- Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit the issue

### Disclosure Policy

We follow a [Coordinated Vulnerability Disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure) policy:

1. **Private Disclosure**: You privately report the vulnerability to us.
2. **Investigation**: We investigate the issue and confirm the vulnerability.
3. **Fix**: We develop a fix for the vulnerability.
4. **Release**: We release a patched version of the software.
5. **Public Disclosure**: We publicly disclose the vulnerability and credit you for the discovery (if desired).

We ask that you do not publicly disclose the vulnerability until we have had a chance to fix it and release a patch.
